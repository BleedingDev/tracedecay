# Interruptible private directory creation draft

Status: APPLIED after root review of the full patch and final 32-checkpoint test refinement. `pm-interruptible-directory.integration.patch` changes only `crates/tracedecay-runtime-core/src/storage/paths_and_io.rs` and `crates/tracedecay-runtime-core/src/storage/tests.rs`. Matching baseline and proposed copies are in `pm-interruptible-directory-baseline/` and `pm-interruptible-directory-proposed/`; applied source files match the approved proposed copies byte for byte.

The additive `PrivateStoreIo::create_dir_all_durable_interruptible(&Path, &mut dyn FnMut() -> io::Result<()>)` reuses the existing Unix, Windows and unsupported-platform bodies with an optional callback. The existing API passes `None` and retains blocking acquisition. The controlled variant opens the private sidecar once with `open_lock_file(path, true)`, uses `FileExt::try_lock_exclusive` and the existing contention classifier, sleeps at most 1 ms between attempts, and checks control before each attempt and immediately after acquiring. The public nonblocking sidecar helper cannot substitute because it opens with `private = false`.

Control is also checked before path discovery, each missing ancestor, and existing-directory retry work. Unix private creation and strict parent sync, Windows staging plus write-through publication and cleanup, and legacy call sites retain their existing behavior. No callback interrupts a started publication before its durability barrier. The callback is cooperative and does not preempt individual filesystem calls. No provider types or policy enter runtime-core.

The runtime regression holds the actual `.child.durable-directory.lock` sidecar while a worker invokes the public controlled API. The callback allows 32 checks to reach repeated contention before returning its original `Interrupted` or `TimedOut` error. The test receives that error before releasing the lock, verifies the destination was absent, and retries after release. A two-second receive timeout releases the lock before joining even on regression, avoiding an indefinite blocked test.

The matching receipt change is `pm-source-command-receipt.interruptible-root.delta.patch`, also included in the refreshed full source-command receipt patch. `prepare_root` captures the exact original `OperationControl` terminal reason in its callback and restores it after the I/O boundary. Host tests cover already-cancelled and already-expired first use without a root or publication, and a live original deadline expiring while the first-use sidecar remains held.

Recon covered the one existing public-to-platform call, all three platform implementations, the Unix common missing-directory loop, both private directory lock acquisitions, the existing private lock opener, and the unchanged append/public lock callers. The graph index predates this worktree's storage split; exact scoped source reads established the current call sites. TraceDecay reported 26,797 tokens saved.

Validation is limited to `rustfmt --edition 2024 --check`, pre-application `git apply --check`, post-application `git diff --check`, and byte equality with the approved proposed files. No Cargo, compiler or tests were run. Root owns module wiring and execution of the drafted tests.
